# Backlog

Offene Wünsche, nach Thema geordnet und in jedem Thema nach Aufwand aufsteigend. Der Aufwand ist grob
geschätzt: **klein** (bis etwa ein Tag), **mittel** (einige Tage), **groß** (ein eigener Meilenstein).

## Funktionen

### KI-Unterstützung

| Aufwand | Wunsch | Anmerkung |
| --- | --- | --- |
| groß | KI-Vorschläge zur Extraktion aus Volltexten | Setzt voraus, dass der Text aus dem PDF gelesen wird; ein Vorschlag je Feld des Formulars. |
| groß | Decision Model in der App für Screening-Entscheidungen | Noch zu klären: Was soll das Modell leisten (Reihenfolge der Einträge, Vorschlag, Stoppregel)? |
| offen | Decision Model über eine API, z. B. JEV | Noch zu klären: welche API und welches Format. Hängt am Punkt darüber. |

### Volltexte

| Aufwand | Wunsch | Anmerkung |
| --- | --- | --- |
| mittel | Extraktion aus Volltexten im Tool | Die Eingabe im Formular neben dem Volltext gibt es schon. Noch zu klären: Was fehlt (etwa markierten Text in ein Feld übernehmen)? |
| groß | Volltexte markieren und kommentieren, mit Farben | Aus Meilenstein 9 offen geblieben. |

### Export

| Aufwand | Wunsch | Anmerkung |
| --- | --- | --- |
| klein | Screening und Extraktion als CSV und JSON | Die Tabelle der eingeschlossenen Quellen gibt es schon als CSV. |
| mittel | Screening und Extraktion als Excel | |
| mittel | Screening und Extraktion für gängige Statistikprogramme | Noch zu klären: welche (R, SPSS, Stata). |

### Protokoll

| Aufwand | Wunsch | Anmerkung |
| --- | --- | --- |
| mittel | Textbausteine für Protokolle | |

### Rückmeldung

| Aufwand | Wunsch | Anmerkung |
| --- | --- | --- |
| klein | Mail an die Entwicklung mit Fehler oder Wunsch | |
